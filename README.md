# María Brie - Sitio Web

Sitio web premium para María Brie · Repostería Artesanal.

## Estructura

- **Inicio** (`/`) - Página principal con hero y 4 líneas de negocio
- **Nosotros** (`/nosotros`) - Historia y filosofía de la marca
- **Empresas** (`/empresas`) - Servicios corporativos con planes de precios
- **Eventos** (`/eventos`) - Mesas de postres y eventos privados
- **Postres** (`/postres`) - Catálogo de productos
- **Lunch Box** - Redirect a lunchbox.mariabrie.com.mx
- **Contacto** (`/contacto`) - Formas de contacto

## Stack

- React 18 + Vite
- React Router (páginas separadas navegables)
- Framer Motion (animaciones)
- Tailwind CSS (estilos)
- Lucide Icons

## Deploy en Vercel

1. Sube este proyecto a GitHub (nuevo repo: `mariabrie-web`)
2. Conecta el repo a Vercel
3. Vercel detecta Vite automáticamente
4. Deploy automático en cada push a `main`

## Dominio

Apuntar `mariabrie.com.mx` al proyecto de Vercel:
- En Vercel: Settings → Domains → Add `mariabrie.com.mx` y `www.mariabrie.com.mx`
- En Squarespace DNS: cambiar el A record y CNAME hacia Vercel
